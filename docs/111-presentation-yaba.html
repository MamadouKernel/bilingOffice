02 · Qui fait quoi

03 / 08

Chaque personne a son espace et sa prochaine étape.

Client société

Prépare une demande, joint les pièces, suit les réponses et agit si un complément est demandé.

Administrateur société

Fait les mêmes démarches et invite les collègues de sa société.

Transporteur

Dépose et suit son dossier chauffeur. Son accès est distinct du compte de facturation.

Agent CIT

Vérifie les dossiers de sa file et explique les compléments ou décisions.

Superviseur

Suit les délais et la charge des équipes de son périmètre.

Administration et support

Gèrent les paramètres autorisés ou aident sur les incidents de la plateforme.

Les accès sont personnels; les comptes ne doivent pas être partagés.

03 · La vie d’une demande

04 / 08

Le statut indique quoi faire ensuite.

1. PréparerRemplir le formulaire et réunir les pièces demandées.
2. EnvoyerLa plateforme confirme la réception et donne une référence.
3. VérifierUn agent examine le dossier dans sa file.
4. RépondreSi un complément est demandé, ajouter les éléments depuis le dossier.
5. TerminerSuivre la décision et récupérer les documents lorsqu’ils sont disponibles.

Ce que voit le client

Le statut, l’historique, les messages et les pièces liées au dossier.

Ce que fait CIT

L’équipe prend en charge, contrôle, demande une précision ou fait avancer le dossier selon la procédure.

Les étapes précises dépendent du type de demande et du profil client.

06 · Aide dans l’application

07 / 08

On peut se faire guider à chaque étape.

« À quoi sert cet écran ? Qu’est-ce que je dois faire ? »

Le bouton Aide explique la page en cours. Le centre d’aide rassemble les fiches. La visite guidée montre les commandes principales.

Si quelque chose bloque

  • Pour une question de dossier : utiliser les échanges du dossier.
  • Pour un problème de la plateforme : signaler un incident.
  • Pour une demande de compte : contacter le référent CIT indiqué.

La simulation proforma aide à estimer un montant. La facture PDF est un document de simulation, non contractuel.

Les menus varient selon le compte; une action absente peut nécessiter un accès supplémentaire.

07 · À retenir

08 / 08

Des dossiers suivis, des responsabilités claires.

Pour la recette

Utiliser un environnement de test, des comptes dédiés et les scénarios du cahier de tests.

Lire le statut, répondre dans le dossier et garder son compte personnel sécurisé.

Pour les équipes CIT

Traiter dans la file attendue, expliquer les demandes de complément et consigner les décisions.

Documentation : guide des parcours, cahier de tests et script de démonstration dans le dossier `docs` du projet.
